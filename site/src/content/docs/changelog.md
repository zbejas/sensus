Release notes are published with every version on
[GitHub Releases](https://github.com/zbejas/sensus/releases). Each release describes what
changed since the previous one; there is no separate changelog to keep in sync here.

To see which version you are running:

```sh
sensus --version
```

The version is embedded in the binary when it is built, so updating means installing a newer
release. Pin a specific one with `--version vx.y.z` when running the installer; see
[Install](/docs/install/).
